## 🔍 发现的问题及修复

### 问题 1: requirements.txt 编码错误
**现象**: `pip install` 时报 `UnicodeDecodeError: 'gbk' codec can't decode byte`

**原因**: 文件包含中文注释,Windows PowerShell 默认使用 GBK 编码

**修复**: 
- 删除原文件
- 重新创建纯 ASCII 版本(移除中文注释)
- 只保留必要的依赖包

**验证**: ✅ 修复后 `pip install` 成功

### 问题 2: 权限管理器黑名单检查顺序错误
**现象**: bypass 模式下,危险命令未被拦截

**原因**: 黑名单检查在 bypass 模式判断之后执行

**修复**:
- 调整检查顺序: 黑名单 → bypass → plan → normal
- 确保黑名单是最高优先级,任何模式都生效

**验证**: ✅ 修复后,即使 bypass 模式也会拦截 `rm -rf /`

### 问题 3: demo_tools.py 缺少导入
**现象**: `NameError: name 'get_tool_schemas' is not defined`

**原因**: 使用了函数但未导入

**修复**: 添加 `get_tool_schemas` 到导入语句

**验证**: ✅ 修复后演示脚本正常运行
