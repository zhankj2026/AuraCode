- 简单：9×9 棋盘，10 个地雷

- 困难：16×30 棋盘，99 个地雷

✅ **完整游戏功能**
- 左键点击揭开方块
- 右键点击标记地雷

### 如何运行

1. 在浏览器中打开 `minesweeper.html`
2. 选择难度级别
3. 点击方块开始游戏

### 游戏规则

- 左键点击方块来揭开
- 右键点击方块来标记地雷（插旗）
- 数字表示周围 8 个方块中的地雷数量
- 揭开所有非地雷方块即可获胜
- 点击到地雷则游戏失败
